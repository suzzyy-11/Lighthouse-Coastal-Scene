🌊 Lighthouse Island

A 3D Tropical Island Environment Built with C, OpenGL & GLUT
Lighthouse Island is a 3D Computer Graphics project created using OpenGL and GLUT. It features a tropical island with a
lighthouse, sailing ship, keeper's house, rescue station, dock, palm trees, campfire, animated ocean, birds, day/night
changes, and storm effects.The environment is generated programmatically without external 3D models or image assets.

✨ Features

🏝️ Island Environment

* Natural-looking island coastline
* Sandy beach and grassy terrain
* Water and shoreline areas
* Pathways, rocks, plants, flowers and environmental details

🗼 Lighthouse

* Detailed striped tower
* Door, windows and balcony
* Lantern room and roof
* Glowing light and rotating beam

🏠 Island Buildings

* Lighthouse keeper's house
* Wooden dock with boat, crates and ropes
* Rescue station with equipment and warning beacon

🌴 Environment

* Palm trees, grass, bushes and flowers
* Animated campfire
* Animated ocean and shoreline foam
* Sailing ship with realistic bobbing movement
* Flying seagulls

🌅 Day & Night

* ☀️ Day mode with sun, clouds and bright ocean
* 🌙 Night mode with moon, stars and glowing lights
* 🔄 Automatic day/night cycle

⛈️ Storm Mode

* Dark clouds and rain
* Lightning effects
* Stronger waves and ship movement
* Fog and increased environmental movement

💡 Lighting

The project demonstrates:

* Sun and moon lighting
* Lighthouse spotlight and beam
* Campfire lighting
* Glowing windows and outdoor lamps

🎮 Controls

| Key         | Action                     |
| ----------- | -------------------------- |
| `D`         | Day                        |
| `N`         | Night                      |
| `A`         | Auto day/night             |
| `Z / X`     | Move time backward/forward |
| `R`         | Toggle storm               |
| `Q / E`     | Storm intensity            |
| `K`         | Toggle lightning           |
| `O`         | Toggle fog                 |
| `L`         | Lighthouse beam            |
| `S`         | Start/stop ship            |
| `W`         | Start/stop waves           |
| `B`         | Bird movement              |
| `F`         | Campfire animation         |
| `SPACE`     | Pause/resume               |
| `1 / 2 / 3` | Camera modes               |
| `+ / -`     | Zoom                       |
| `H`         | Show/hide HUD              |
| `ESC`       | Exit                       |

🛠️ Technologies

* C
* OpenGL
* GLUT / FreeGLUT
* Code::Blocks 20.03
* Windows
No external 3D models, textures or image files are required.

▶️ How to Run

Open the project in Code::Blocks 20.03, make sure FreeGLUT and OpenGL are properly configured, then build and run using `F9`.

Required libraries:

```text
freeglut
opengl32
glu32
winmm
gdi32
```
